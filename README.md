Password Strength Analyzer

About the Project

Password Strength Analyzer is a web-based cybersecurity project that checks password strength and provides security recommendations.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- Password strength detection
- Weak, Medium and Strong classification
- Show/Hide password
- Security recommendations
- Password strength indicator

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Enter a dummy password to test the analyzer.

Project Purpose

This project aims to educate users about password security and encourage the use of stronger passwords.
